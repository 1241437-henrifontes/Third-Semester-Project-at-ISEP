# Glossary

| Name                     | Description                                                                                                                                                                                   |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Acceleration             | A performance measure of locomotives, representing how fast they can reach operating speed.                                                                                                   |
| Acceptance Criteria      | Conditions that a user story must satisfy for stakeholders to consider it complete.                                                                                                           |
| Aisle                    | Passage between rows of bays in a warehouse, used for access and picking operations.                                                                                                          |
| Bay                      | A storage space in a warehouse aisle where product boxes are stored, with a defined capacity.                                                                                                 |
| Best Fit Decreasing      | A packing heuristic that places items in the trolley that results in the smallest remaining capacity after insertion.                                                                         |
| Box                      | A container unit of one product (SKU), with quantity and possibly an expiry date.                                                                                                             |
| Boxcar                   | Enclosed wagon type used for general cargo, protecting goods from weather.                                                                                                                    |
| Capacity                 | Maximum number of boxes a bay or warehouse can hold.                                                                                                                                          |
| Cargo Handling           | Operations of loading, unloading, sorting, storing, and dispatching goods at terminals or warehouses.                                                                                         |
| Chemical Tank Car        | Specialized tank wagon optimized for transporting chemicals with varying densities and purity specifications.                                                                                 |
| Conceptual Model         | High-level representation of business concepts and relationships in the system domain.                                                                                                        |
| Consist                  | The ordered set of locomotives and wagons that form a train.                                                                                                                                  |
| Container                | A standardized unit (20ft, 40ft, 45ft) for transporting goods, usually carried on flatcars.                                                                                                   |
| Deterministic Sweep      | A picking sequence strategy that orders bay visits by ascending aisle and calculates distance accordingly.                                                                                    |
| Dispatching              | The process of assigning and moving trains according to schedules and routes.                                                                                                                 |
| Dock                     | Physical loading/unloading position at a terminal or warehouse, often equipped with a leveler and shelter.                                                                                    |
| Domain Model             | Representation of key business entities and rules relevant to the system.                                                                                                                     |
| Emergency Stop Order     | Instruction issued by a station operator when an arriving train cannot be assigned a track safely.                                                                                            |
| Endpoint                 | A terminal point of a railway line, may serve as origin, destination, or interchange.                                                                                                         |
| FEFO                     | First Expired, First Out.                                                                                                                                                                     |
| FIFO                     | First In, First Out.                                                                                                                                                                          |
| First Expired, First Out | Inventory rule where perishable goods are dispatched in order of earliest expiry.                                                                                                             |
| First Fit                | Packing heuristic that places an item into the first trolley where it fits.                                                                                                                   |
| First Fit Decreasing     | Packing heuristic that sorts items by decreasing weight before applying First Fit.                                                                                                            |
| First In, First Out      | Inventory rule where non-perishable goods are dispatched in order of arrival.                                                                                                                 |
| Flatcar                  | A type of wagon used for transporting containers, vehicles, or heavy machinery.                                                                                                               |
| Freight Manager          | User responsible for coordinating freight movement and wagon allocation.                                                                                                                      |
| Freight Yard             | Facility for assembling, disassembling, and storing wagons before departure.                                                                                                                  |
| Fuel Capacity            | The total volume of fuel that a diesel locomotive can carry.                                                                                                                                  |
| Gauge                    | The width between rails of a line segment; determines compatibility of rolling stock.                                                                                                         |
| Grain Silo               | Facility for storing bulk agricultural products at a terminal or warehouse.                                                                                                                   |
| Hopper Car               | Wagon type designed to transport bulk materials such as coal, grain, or minerals.                                                                                                             |
| Intermodal Terminal      | Facility where goods are transferred between transport modes (rail, road, sea).                                                                                                               |
| Light Sign               | A visual indicator at each track showing its operational state (free, busy, assigned, or inoperative).                                                                                        |
| Line                     | A connection between two endpoints, composed of one or more line segments.                                                                                                                    |
| Line Segment             | A portion of a railway line, with attributes such as track type, gaugeId, electrification, and speed limit.                                                                                     |
| Locomotive               | Powered vehicle that pulls freight trains, can be diesel or electric.                                                                                                                         |
| Maintenance              | Actions required to keep rail infrastructure and rolling stock in safe, working condition.                                                                                                    |
| Median                   | The middle value in a sorted numerical list, used in statistical analysis.                                                                                                                    |
| Mineral Oil Car          | Specialized tank wagon for petrochemicals and mineral oils.                                                                                                                                   |
| Nearest Neighbour Strategy | A greedy picking strategy that selects the next closest bay based on distance calculations.                                                                                                |
| Operator                 | Entity that manages locomotives and wagons.                                                                                                                                                   |
| Order                    | A request to deliver certain quantities of products from warehouse stock.                                                                                                                     |
| Owner                    | Entity responsible for the maintenance and operation rights of a railway line.                                                                                                                |
| Path                     | The ordered list of stations a train must pass through to reach its destination.                                                                                                               |
| Picking                  | Process of collecting products from warehouse bays to fulfill orders.                                                                                                                          |
| Picking Plan             | The structured sequence of picking tasks created to dispatch orders efficiently.                                                                                                              |
| Pressure Gas Car         | Tank wagon designed for transporting liquefied or pressurized gases.                                                                                                                         |
| Quarantine               | Temporary state where returned goods are held for inspection before restock or discard.                                                                                                       |
| Railway Infrastructure   | Physical railway network: lines, stations, terminals, yards, and sidings.                                                                                                                     |
| Railway System           | The overall system of trains, tracks, rolling stock, and operations for freight.                                                                                                              |
| Refrigerated Car         | Wagon type used for perishable goods requiring controlled temperature.                                                                                                                        |
| Relational Model         | Logical database schema organizing entities, attributes, and relationships.                                                                                                                   |
| Rolling Stock            | All railway vehicles, including locomotives and wagons.                                                                                                                                       |
| Route                    | The ordered sequence of stations that a train follows from origin to destination.                                                                                                             |
| Scheduler / Planner      | User who creates and manages train timetables.                                                                                                                                                |
| SCRUM                    | Agile framework for managing projects in short iterative cycles (sprints).                                                                                                                    |
| Signal                   | Visual or electronic device conveying movement authority and speed restrictions to train drivers.                                                                                             |
| Sidings                  | A secondary track allowing trains to cross or wait on single-track lines.                                                                                                                     |
| SKU                      | Stock Keeping Unit.                                                                                                                                                                           |
| Station                  | Facility where trains stop for loading, unloading, or crossing.                                                                                                                               |
| Station Master           | User responsible for overseeing facility operations, arrivals, and departures.                                                                                                                |
| Station Operator         | User responsible for coordinating train traffic, assigning tracks, and issuing stop or departure orders.                                                                                      |
| Stock Keeping Unit       | Unique identifier for a product in warehouse/inventory management.                                                                                                                            |
| Storage Manager          | User responsible for warehouse stock, bays, and inventory control.                                                                                                                            |
| Synoptic Board           | Console-based board displaying station status, track states, temperature, humidity, and operational data.                                                                                    |
| Tank Car                 | Wagon type for transporting liquids, chemicals, fuels, or pressurized gases.                                                                                                                  |
| Terminal                 | A railway facility specialized in freight operations, equipped for loading, unloading, storage, and transfer of goods.                                                                        |
| Timetable                | Scheduled plan of train arrivals, departures, and route allocations.                                                                                                                          |
| Track (Single / Double)  | Track type: single requires sidings; double allows simultaneous two-way travel.                                                                                                               |
| Train Driver             | User who operates locomotives and ensures safe journeys.                                                                                                                                      |
| Train Path               | A pre-allocated slot (route and time window) on the network reserved for a specific train.                                                                                                    |
| Tare                     | The empty (unladen) weight of a wagon.                                                                                                                                                        |
| Trolley                  | A cart used by pickers to transport collected items within weight capacity limits.                                                                                                            |
| Wagon                    | Railway vehicle for transporting goods. Types include boxcar, flatcar, tank car, hopper car, and refrigerated car.                                                                            |
